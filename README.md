# PDFtoPDF.in

A lightweight, upload-first PDF tools homepage hosted with GitHub Pages.

## Current frontend
- Responsive IBM Carbon-inspired layout
- Drag-and-drop or button-based file selection
- Browser-rendered PDF page previews
- Remove pages and drag to reorder
- JPG/PNG/WebP images to PDF
- Export/re-save selected PDF pages
- SEO metadata, canonical URL, Open Graph tags and WebApplication structured data
- About, Privacy Policy, Terms of Use, Disclaimer and Contact pages

## Important limitations
- Word/Excel/PowerPoint conversions are listed as planned options but are not yet enabled.
- Advanced compression is not implemented; re-saving a PDF is not equivalent to compression.
- Split PDF currently exports the selected page sequence as a PDF rather than creating multiple output files.
- PDF-to-JPG currently exports the first selected page only.
- Files for supported browser-based actions are processed locally in the browser. Third-party libraries are loaded from CDNs.
- Before applying for AdSense, configure a real support contact, test all tool flows, and ensure the privacy policy accurately reflects any analytics and advertising scripts actually installed.

## Deploy
The custom domain is configured in the CNAME file as pdftopdf.in. GitHub Pages must be enabled for the main branch and root folder in repository settings.
